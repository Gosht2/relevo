# Relevo

Sistema de continuidad de tareas entre turnos de trabajo.

## Descripción

Relevo permitirá que los empleados registren las tareas pendientes al finalizar su turno. La persona que reciba el siguiente turno podrá consultar qué se hizo, qué falta y cuál es el próximo paso. Cada entrega conservará el historial y la confirmación de recepción para facilitar la continuidad del trabajo.

## Objetivo

Desarrollar un sistema que facilite la entrega y recepción de pendientes entre turnos, reduciendo los olvidos y la pérdida de información, y permitiendo identificar quién entrega y quién recibe cada tarea.

## Alcance inicial

- Registrar pendientes con descripción, prioridad y próximo paso.
- Entregar pendientes al siguiente turno y confirmar su recepción.
- Consultar tareas pendientes, en proceso y resueltas.
- Conservar un historial de cambios y responsables.

## Herramientas

- GitHub: repositorio e historial de cambios.
- GitHub Issues: registro y seguimiento de tareas del proyecto.
- GitHub Projects: tablero de organización del trabajo, pendiente de configurar.
- Markdown: documentación del repositorio.

El lenguaje, el entorno de desarrollo y la base de datos se definirán durante la planificación técnica.

## Organización del trabajo

El trabajo se dividirá en tareas pequeñas registradas como issues. Se organizarán en un tablero de GitHub Projects con los estados Por hacer, En proceso y Terminado. Cada cambio se guardará mediante commits con mensajes que describan su propósito.

Primero se definirán los requisitos y el diseño; después se implementarán las funciones y se comprobará su funcionamiento. Las capturas y el documento de entrega se conservarán en este repositorio.

## Estructura prevista

- `src/`: código fuente de la aplicación.
